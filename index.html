Request a withdrawal

Submit a withdrawal request for administrator review. Submitting this form does not guarantee approval or payment.

Withdrawal conditions
  • Minimum request: UGX 2,000.
  • Fee: 10% of the requested amount.
  • The fee is deducted from the requested amount when calculating the expected payout.
  • Processing schedule: Monday–Saturday, 6:00 AM–8:00 PM Uganda time, excluding public holidays.
  • Only one pending withdrawal request is permitted per member.
The server must verify the schedule, public holidays, available balance and pending-request limit before any real withdrawal is approved.

Apply to Become an Agent

An agent must be an active Plus member and submit an application. Plus membership alone does not make you an approved agent.

Minimum starting capital: UGX 50,000.

You may contribute UGX 50,000 or more. After an administrator verifies your actual starting capital, the system will calculate a bonus equal to 15% of that capital.

Total restricted float = starting capital + 15% bonus. The float is non-withdrawable and restricted to facilitating member package activation.

Your NIN is private and should only be accessible to you and authorised administrators. It will not be shown in public agent search results.
